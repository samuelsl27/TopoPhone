# Skill `spec-generator`

Basada en la skill del mismo nombre de [mouredev/hello-sdd](https://github.com/mouredev/hello-sdd) (Apache-2.0), adaptada a TopoPhone.

- **Claude Code** la detecta automáticamente en `.claude/skills/`. También se puede invocar a mano con `/spec-generator`.
- **opencode**: copia o enlaza la carpeta en `.opencode/skill/spec-generator`.

Archivos:
- `SKILL.md`: instrucciones (entrevista, reglas, notación EARS, revisión).
- `spec-template.md`: plantilla de `spec.md`.

Las plantillas de `plan.md` y `tasks.md` están en `docs/plantillas/`. Los prompts de cada fase están en `docs/prompts-sdd.md`.
